# Retrieval: BM25 and lexical refinements

Run `uv run python notebooks/retrieval/run_step.py` from the repository root, or execute `03_retrieval.ipynb`.

Requires a validated Step 5 bundle. This single entry point builds the baseline index, adds lexical refinements, compares retrieval, and displays source evidence. No separate Step 6 notebook or prebuilt index is needed. Historical artifact locations remain `artifacts/step-06/` and `artifacts/step-07/`. See [scope and limitations](../../docs/modeling/07-enhanced-retrieval.md). Clinical accuracy and mobile performance are not yet established.
